# 历史文件与本交付工作区范围

## 1. 交付原则

dev_ws_sdf_gripper 是从原始 dev_ws 复制后整理的独立交付工作区。原始目录不修改、不删除。交付工作区保留当前运行链路需要的源码、模型、配置和说明。

## 2. 当前运行入口

| 功能 | 当前入口 |
|---|---|
| AG165 Gazebo 模型 | src/cr7as_grasp/urdf/cr7as_ag165_gazebo.urdf.xacro |
| AG165 宏与闭环 | src/cr7as_grasp/urdf/ag165_macro.xacro |
| Gazebo 启动 | src/cr7as_grasp/launch/gazebo_ag165_control.launch.py |
| MoveIt robot description | src/cr7as_grasp_moveit_config/config/cr7as_grasp.urdf.xacro |
| 完整场景 | src/cr7as_vision_grasp/launch/spawn_grasp_scene.launch.py |
| 抓取执行器 | src/cr7as_vision_motion/src/pick_place_executor.cpp |
| 工件附着 | src/cr7as_gazebo_grasp/cr7as_gazebo_grasp/attachment_follower.py |

## 3. 兼容文件

工作区仍可能保留旧 AG95 运行入口和模型用于回退对照，但它们不会被 AG165 完整场景自动调用：

~~~text
src/cr7as_grasp/urdf/ag95_macro.xacro
src/cr7as_grasp/urdf/cr7as_grasp.urdf.xacro
src/cr7as_grasp/urdf/cr7as_grasp_gazebo.urdf.xacro
src/cr7as_grasp/launch/gazebo_control.launch.py
~~~

不要把旧入口和 AG165 入口同时启动。备份文件、Python __pycache__ 和构建目录不属于运行链路；本交付包已移除同名备份和缓存，原始 dev_ws 中的备份仍保留。

## 4. 判断文件是否生效

以入口引用和编译安装规则为准：launch 被当前入口 include、Xacro 被 robot_description include、YAML 被节点加载、Python/C++ 出现在 setup.py/CMakeLists.txt，或模型被 spawn_entity.py/安装规则引用。
