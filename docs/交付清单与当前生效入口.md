## 验收门槛

1. `colcon build` 全部通过；
2. Xacro 展开和 `check_urdf` 通过；
3. `ros2 control list_controllers` 显示三个控制器 active；
4. `ag165_joint1_left` action 能张开/闭合，`/joint_states` 有 position/velocity；
5. 左右夹爪机构不炸模，SDF pin 闭环没有明显脱开；
6. 完整场景中工件、桌面和料箱 collision 都存在；
7. `gazebo_attachment_follower` 节点真实存在；
8. `/get_entity_state`、`/set_entity_state` 能调用；
9. 抓取只有在 attachment confirmation 后才允许 lift；
10. detach 后工件能在料箱中重新参与物理碰撞。

## 失败分类

- 编译失败：先看包依赖、CMake 源文件和 Python 环境；
- 控制器失败：看 joint 名称是否仍是旧 AG95；
- 闭环抖动：看 pin 坐标、轴、从动关节限位和是否重复控制；
- 物体被推走：看 TCP 高度、指尖 collision、下降速度和接触几何；
- 附着失败：先看 follower 节点、服务服务器和 Gazebo 状态服务，再看抓取位姿；
- MoveIt 规划失败：确认 MoveIt 与 Gazebo 使用同一份 AG165 robot description。
