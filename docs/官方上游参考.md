# 大寰官方上游参考

## 已核对的官方仓库

- 官方组织：[DH-Robotics](https://github.com/DH-Robotics)
- 官方公开 ROS 仓库：[DH-Robotics/dh_gripper_ros](https://github.com/DH-Robotics/dh_gripper_ros)

截至本仓库本次整理，官方组织公开的夹爪 ROS 代码只有上述 `dh_gripper_ros`。它是 ROS 1 元包，公开目录包括 `dh_gripper_driver`、`dh_gripper_msgs`、AG95、AG145、PGC140 和 DH3 的模型/驱动资料；**不包含 AG165-90 专用包**。

## 关于“新版 ROS 2”

GitHub 中能找到 ROS 2/Humble 版本的移植项目，例如 [Techolution/dh_gripper_ros2](https://github.com/Techolution/dh_gripper_ros2)，但该仓库是第三方 fork，并非大寰官方发布。使用时应自行核对许可证、控制协议、固件版本和型号支持范围，不能作为 AG165-90 官方驱动或官方几何模型的依据。

## 本仓库与上游的关系

本仓库不复制或伪称存在 AG165-90 官方 GitHub 包。它保存的 AG165-90 CAD、URDF/Xacro、SDF 闭环和 Gazebo 插件，均是针对现有 AG165-90 模型的工程整理与验证结果。真机通信、寄存器和状态码必须以相应固件版本的官方手册为准。
