# 01：机器人模型契约

## 模型来源与用途

`cr7as_grasp` 起源于 SolidWorks SW2URDF 导出包，已转换为 ROS 2 Humble 的 `ament_cmake` 包。URDF XML 负责描述 link/joint/mesh；ROS 2 适配主要涉及 launch、资源安装和 Gazebo 控制接口。

| 文件 | 用途 | 不应承担的职责 |
|---|---|---|
| `urdf/cr7as_grasp.urdf` | RViz2、Robot State Publisher、模型检查 | Gazebo 控制插件。 |
| `urdf/cr7as_grasp_gazebo.urdf` | Gazebo Classic 与 `gazebo_ros2_control` | 真实控制器配置。 |
| `config/gazebo_controllers.yaml` | 仿真 `joint_state_broadcaster` / `arm_controller` | 越疆 V4 实机控制器。 |

## link 与末端工具链

项目模型的末端链按以下约定使用：

```text
base_link -> b0 -> l1 -> l2 -> l3 -> l4 -> l5 -> l6
                                             -> gripper_base
                                                  -> grasp_tcp
```

- `gripper_base`：固定夹爪安装基座；
- `grasp_tcp`：抓取规划、视觉目标与 MoveIt 的工具中心点；
- `grasp_tcp` 没有有效 STL 几何，应作为纯坐标系 link 使用；
- 夹爪开合机构尚未建模，不能由这个包完成真实夹爪控制。

官方 V4 `cr7` 模型止于第六轴/`Link6`，没有本项目的夹爪和 TCP。因此官方模型不能取代本项目的末端工具链。

## 关节命名映射

项目与官方 V4 CR7 的关节按用户确认一一对应：

| CR7AS 仿真 / MoveIt | 官方 V4 CR7 | 映射状态 |
|---|---|---|
| `j1` | `joint1` | 已确认一一对应 |
| `j2` | `joint2` | 已确认一一对应 |
| `j3` | `joint3` | 已确认一一对应 |
| `j4` | `joint4` | 已确认一一对应 |
| `j5` | `joint5` | 已确认一一对应 |
| `j6` | `joint6` | 已确认一一对应 |

该映射只用于名称适配；本项目仍以 `j1..j6` 作为现有 URDF、Gazebo 与 MoveIt 文件中的内部命名，避免破坏已验证仿真。

## 质量、惯性、惯量：强制约束

> **官方越疆 V4 CR7 URDF 的质量、惯性、惯量不准确，不能用于本 CR7AS 的 Gazebo 仿真。**

因此：

1. 保留 `cr7as_grasp` 现有 URDF / Gazebo URDF 中的 CR7AS 质量、惯性、惯量；
2. 不从 `DOBOT_6Axis_ROS2_V4-main/dobot_rviz/urdf/cr7_robot.urdf` 拷贝、覆盖或推导这些值；
3. 这些 CR7AS 参数当前用于仿真稳定性和模型连续性，**并非真实硬件动力学认证值**；
4. 若以后做高保真动力学、力控、payload 或真实碰撞安全评估，必须用厂家正式数据或独立测量结果替换并记录版本来源。

## 关节限位与碰撞网格

- 关节限位、轴向、零位和正方向必须以当前 CR7AS 模型与实机验证为准；
- visual 与 collision 目前均使用较详细的 STL；做高频规划或动力学时应建立简化碰撞网格；
- 不得把 Gazebo 中临时配置的 effort、velocity、阻尼和摩擦直接解释为真实机械臂额定参数。
