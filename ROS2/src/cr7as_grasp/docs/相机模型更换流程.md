# CR7AS + AG95 相机模型更换流程

> 文档版本：2026-09-18  
> 适用系统：Ubuntu 22.04 + ROS 2 Humble + Gazebo Classic + MoveIt 2  
> 适用工作区：`~/Desktop/dev_ws`

## 1. 文档目的

本文档用于说明在 CR7AS 六轴机械臂和大寰 AG95 夹爪模型已经接入后，如何安全替换当前的虚拟相机模型。

当前原则是：

- 先完成 AG95、Gazebo 和 MoveIt 的验证；
- 更换相机时只修改相机相关 link、joint 和 Gazebo sensor；
- 不改变 `gripper_base`、`gripper_base_j`、`grasp_tcp` 和 `grasp_tcp_j`；
- RViz/MoveIt 与 Gazebo 使用同一套相机坐标系；
- 不直接修改由 Xacro 生成的静态 `.urdf` 文件作为长期方案。

## 4. 当前阶段是否需要立即删除虚拟相机

不建议在 AG95 和 MoveIt 尚未验证完成时立即删除虚拟相机。

当前虚拟相机固定在：

```text
base_link
```

它不会改变：

```text
j1 ~ j6
AG95 夹爪
l6
 gripper_base
 grasp_tcp
```

建议先保留当前虚拟相机，完成以下测试：

```text
1. Gazebo 能正常启动
2. arm_controller 正常
3. gripper_controller 正常
4. RViz 与 Gazebo 同步
5. MoveIt 能规划六轴
6. MoveIt 能规划 AG95 夹爪
```

完成后再单独更换相机，便于区分问题来源。

## 5. 推荐的相机文件组织方式

不要把新相机的所有 link 和 joint 直接继续堆放在主机械臂 Xacro 文件末尾。

建议新增独立相机宏文件：

```text
~/Desktop/dev_ws/src/cr7as_grasp/urdf/camera_macro.xacro
```

推荐目录结构：

```text
cr7as_grasp/
├── urdf/
│   ├── ag95_macro.xacro
│   ├── camera_macro.xacro
│   ├── cr7as_grasp.urdf.xacro
│   └── cr7as_grasp_gazebo.urdf.xacro
├── meshes/
│   └── camera/
│       ├── visual/
│       └── collision/
└── launch/
```

如果新相机包含多个零件，建议继续拆分：

```text
camera_macro.xacro
camera_gazebo.xacro
```

其中：

- `camera_macro.xacro`：link、visual、collision、inertial、fixed joint；
- `camera_gazebo.xacro`：Gazebo sensor、ROS 相机插件和话题配置。

## 6. 新相机模型必须确定的内容

导入新相机前，先确认厂家或 CAD 导出的模型信息：

### 6.1 相机安装父坐标系

如果安装在机械臂底座：

```xml
<parent link="base_link" />
```

如果安装在机械臂末端：

```xml
<parent link="gripper_base" />
```

如果相机严格安装在 TCP 上：

```xml
<parent link="grasp_tcp" />
```

### 6.2 相机坐标系

至少需要：

```text
camera_link
camera_optical_frame
```

ROS 相机通常使用：

```text
camera_link
└── camera_optical_frame
```

### 6.3 安装位姿

需要确定：

```xml
<origin xyz="x y z" rpy="roll pitch yaw" />
```

其中：

- `xyz` 单位为米；
- `rpy` 单位为弧度；
- `camera_link` 相对于安装父坐标系定义；
- 不要通过修改 `grasp_tcp_j` 来适配相机。

### 6.4 网格文件单位

如果 STL/DAE 文件单位是毫米，通常需要：

```xml
scale="0.001 0.001 0.001"
```

如果模型已经是米，不要重复缩放。

## 7. 删除旧虚拟相机

### 7.1 修改 RViz / MoveIt Xacro

打开：

```text
~/Desktop/dev_ws/src/cr7as_grasp/urdf/cr7as_grasp.urdf.xacro
```

删除从：

```xml
<!-- ================= 虚拟相机 ================= -->
```

到：

```xml
<!-- ================= 虚拟相机结束 ================= -->
```

范围内的相机定义，包括：

```text
virtual_camera_link
base_to_virtual_camera_joint
virtual_camera_optical_frame
virtual_camera_optical_joint
```

不要删除：

```text
grasp_tcp
grasp_tcp_j
```

### 7.2 修改 Gazebo Xacro

打开：

```text
~/Desktop/dev_ws/src/cr7as_grasp/urdf/cr7as_grasp_gazebo.urdf.xacro
```

删除旧的：

```text
virtual_camera_link
base_to_virtual_camera_joint
virtual_camera_optical_frame
virtual_camera_optical_joint
```

同时删除：

```xml
<gazebo reference="virtual_camera_link">
  ...
</gazebo>
```

这一部分中包含：

```text
virtual_camera_sensor
libgazebo_ros_camera.so
/virtual_camera
virtual_camera_optical_frame
```

不能只删除 visual 而保留 sensor，也不能只删除 sensor 而保留旧的 camera link，否则会出现孤立 frame 或传感器挂载失败。

## 8. 导入新相机的推荐方式

### 8.1 在相机宏中定义基本模型

示意结构：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro">

  <xacro:macro name="camera_model"
               params="parent *origin">

    <link name="camera_link">
      <inertial>
        <origin xyz="0 0 0" rpy="0 0 0" />
        <mass value="0.1" />
        <inertia
          ixx="0.0001"
          ixy="0"
          ixz="0"
          iyy="0.0001"
          iyz="0"
          izz="0.0001" />
      </inertial>

      <visual>
        <geometry>
          <mesh
            filename="package://cr7as_grasp/meshes/camera/visual/camera.stl"
            scale="0.001 0.001 0.001" />
        </geometry>
      </visual>

      <collision>
        <geometry>
          <mesh
            filename="package://cr7as_grasp/meshes/camera/collision/camera.stl"
            scale="0.001 0.001 0.001" />
        </geometry>
      </collision>
    </link>

    <joint name="camera_mount_joint" type="fixed">
      <parent link="${parent}" />
      <child link="camera_link" />
      <xacro:insert_block name="origin" />
    </joint>

    <link name="camera_optical_frame" />

    <joint name="camera_optical_joint" type="fixed">
      <parent link="camera_link" />
      <child link="camera_optical_frame" />
      <origin xyz="0 0 0" rpy="-1.5708 0 -1.5708" />
    </joint>

  </xacro:macro>
</robot>
```

实际尺寸、质量、惯量和网格路径需要根据新相机文件修改。

### 8.2 在普通机器人 Xacro 中加载

在：

```text
cr7as_grasp.urdf.xacro
```

中添加：

```xml
<xacro:include
  filename="$(find cr7as_grasp)/urdf/camera_macro.xacro" />
```

然后调用：

```xml
<xacro:camera_model parent="base_link">
  <origin
    xyz="0.0 0.5 1.2"
    rpy="0 1.5708 0" />
</xacro:camera_model>
```

如果相机安装在末端，例如：

```xml
<xacro:camera_model parent="grasp_tcp">
  <origin
    xyz="0 0 0.08"
    rpy="0 0 0" />
</xacro:camera_model>
```

### 8.3 在 Gazebo Xacro 中加载

在：

```text
cr7as_grasp_gazebo.urdf.xacro
```

中加载相同的相机 link/joint 宏，并另外添加 Gazebo sensor：

```xml
<gazebo reference="camera_link">
  <sensor name="camera_sensor" type="camera">
    <always_on>true</always_on>
    <update_rate>30.0</update_rate>
    <visualize>true</visualize>

    <camera>
      <horizontal_fov>1.0472</horizontal_fov>
      <image>
        <width>1280</width>
        <height>720</height>
        <format>R8G8B8</format>
      </image>
      <clip>
        <near>0.05</near>
        <far>5.0</far>
      </clip>
    </camera>

    <plugin
      name="camera_ros_plugin"
      filename="libgazebo_ros_camera.so">
      <ros>
        <namespace>/camera</namespace>
      </ros>
      <camera_name>camera</camera_name>
      <frame_name>camera_optical_frame</frame_name>
    </plugin>
  </sensor>
</gazebo>
```

RViz/MoveIt 和 Gazebo 应使用相同的：

```text
camera_link
camera_optical_frame
```

但只有 Gazebo Xacro 中需要加入真实的 sensor 插件。

如果新相机有 collision 模型，重新生成自碰撞矩阵。

启动：

```bash

ros2 launch moveit_setup_assistant setup_assistant.launch.py
```

进入：

```text
Self-Collisions
```

执行：

```text
Generate Collision Matrix
```

检查新相机与以下 link 的碰撞关系：

```text
l6
gripper_base
dh_ag95_base_link
dh_ag95_body
AG95 手指 link
```

如果相机安装在底座，重点检查它与底座和机械臂初始姿态的碰撞。

如果相机安装在夹爪，重点检查它与 AG95 和抓取对象的碰撞。

不要因为初始姿态没有碰撞，就把所有相机与手指的碰撞全部禁用。

## 15. 更换相机后的最终验收清单

### 模型和坐标系

- [ ] 旧的 `virtual_camera_*` 已从两个活动 Xacro 中删除；
- [ ] 新相机有唯一的 link 名称；
- [ ] 新相机有 `camera_link`；
- [ ] 新相机有 `camera_optical_frame`；
- [ ] 相机父 link 正确；
- [ ] 相机的 xyz/rpy 正确；
- [ ] `gripper_base` 未修改；
- [ ] `grasp_tcp` 未修改；
- [ ] `grasp_tcp_j` 的 xyz 仍为 `0 0.00071813 0.18132`。

### RViz / MoveIt

- [ ] RViz 中新相机模型正常显示；
- [ ] MoveIt 能加载新的 Robot Description；
- [ ] 自碰撞矩阵已经重新生成；
- [ ] ARM 组仍包含 j1 到 j6；
- [ ] gripper 组仍只控制 `dh_left_outer_knuckle_joint`；
- [ ] AG95 mimic 关节没有被误设为主动控制关节。

### Gazebo

- [ ] Gazebo 能正常加载机器人；
- [ ] Gazebo sensor 插件正常加载；
- [ ] 图像话题正常发布；
- [ ] 相机 optical frame 正确；
- [ ] Gazebo 与 RViz 使用同一套 robot_description；
- [ ] `/clock` 正常运行；
- [ ] `use_sim_time` 保持一致。

### 控制器

- [ ] `joint_state_broadcaster` 为 active；
- [ ] `arm_controller` 为 active；
- [ ] `gripper_controller` 为 active；
- [ ] MoveIt 能发现 `/arm_controller/follow_joint_trajectory`；
- [ ] MoveIt 能发现 `/gripper_controller/follow_joint_trajectory`。

## 17. 最终建议

当前不需要删除：

```text
cr7as_grasp_moveit_config/config/cr7as_grasp.urdf.xacro
```

它只是 MoveIt 的 Xacro 加载入口。

正确的长期方案是：

```text
MoveIt 入口 Xacro
    ↓
cr7as_grasp.urdf.xacro
    ├── 机械臂
    ├── AG95
    ├── grasp_tcp
    └── camera_macro.xacro

Gazebo Xacro
    ├── 机械臂
    ├── AG95
    ├── grasp_tcp
    ├── camera_macro.xacro
    └── Gazebo camera sensor/plugin
```

这样以后再次更换相机时，只需要替换相机宏和 Gazebo sensor 配置，不需要重新修改机械臂、AG95 或 TCP 坐标。
