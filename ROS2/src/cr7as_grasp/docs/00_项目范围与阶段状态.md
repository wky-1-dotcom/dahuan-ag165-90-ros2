# 00：项目范围与阶段状态

## 目标

本项目在 ROS 2 Humble 下实现 CR7AS 的仿真视觉引导抓取原型，并为未来越疆 V4 控制器接入预留明确边界。

## 设备范围

- 本体：CR7AS 六轴机械臂；
- 工具：固定 `gripper_base` 与固定工具坐标 `grasp_tcp`；
- 仿真：RViz2、Gazebo Classic、`gazebo_ros2_control`、MoveIt 2；
- 视觉：Gazebo 虚拟 RGB 相机；
- 后续硬件接口：越疆 V4 ROS 2 Humble SDK（以官方 `cr7` 接口作为参考）。

## CR7AS 与 CR7 的本项目假设

CR7AS 相比 CR7 的额外能力为皮肤检测。皮肤检测没有进入当前机器人运动学、URDF、Gazebo Classic 或 MoveIt 的仿真目标，因此：

```text
当前仿真运动学/控制器接口：按 CR7 对照
皮肤检测：本阶段不建模、不订阅、不参与安全判断
```

这不表示皮肤检测在实机安全功能中可以忽略；只表示它不属于当前仿真范围。

## 阶段定义

| 阶段 | 输入 | 输出 | 状态 | 验收边界 |
|---|---|---|---|---|
| P0 | URDF / mesh | RViz、Gazebo 六轴模型 | 已完成（仿真） | 能发布完整 TF，仿真六轴可被控制。 |
| P1 | RGB 图像 | 目标像素坐标 | 已完成（仿真） | HSV 检测、调试图像、有效标志正常。 |
| P2 | 像素、内参、TF、平面高度 | `base_link` 下米单位位姿 | 已完成（仿真） | 单位为米，`frame_id=base_link`。 |
| P3.1 | P2 位姿 | 预抓取/抓取/抬升候选位姿、仅规划轨迹 | 已完成（仅规划） | 绝不执行机械臂。 |
| P3.2 | 已验证 P3.1 轨迹 | Gazebo 单段受控执行 | 未开始 | 有桌面/物体碰撞场景和回退策略。 |
| P3.3 | 预抓取位姿 | 下探与抬升轨迹 | 未开始 | 笛卡尔路径、碰撞、安全距离均验证。 |
| P4 | 抓取候选 | 夹爪开合、物体附着逻辑 | 未开始 | 夹爪接口、失败处理和释放流程明确。 |
| P5 | 现场参数、V4 驱动 | 仅检查的实机接口验证 | 未开始 | TCP/Tool/IO/关节映射及可达性检查通过。 |
| P6 | 标定视觉与实机 | 低速、人工确认的实机抓取 | 未开始 | 逐项完成实机前置验收。 |

## 当前禁止事项

- 禁止将 P3.1 的 `plan_pregrasp` 结果直接用于实机执行；
- 禁止因官方 V4 CR7 URDF 存在而替换本 CR7AS 模型的质量、惯性或惯量；
- 禁止把 `grasp_tcp` 当作已在控制器内标定的 Tool TCP；
- 禁止猜测夹爪 IO 的通道、极性、Tool ID 或 payload。
